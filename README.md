# CampusSpace

Учебный проект по бронированию аудиторий, коворкингов, переговорных и компьютерных классов. Данные кампуса и учётные записи вымышлены.

## Запуск

Понадобятся Node.js 24 LTS и pnpm. Выполните команды в каталоге проекта.

```sh
pnpm install --frozen-lockfile
pnpm start
```

Откройте [CampusSpace](http://127.0.0.1:3000). При первом запуске создаётся `data/campusspace.sqlite` с демонстрационными данными. Bootstrap загружается локально. Для разработки с перезапуском используйте `pnpm dev`.

## Код и документация

- `public/` — адаптивный интерфейс на Bootstrap и JavaScript.
- `src/` — HTTP-сервер, правила бронирования, модель SQLite и демонстрационные данные.
- [Диаграмма базы данных](docs/database.md) и [SQL-схема](src/schema.sql) описывают 13 связанных сущностей.
- [Документация API](http://127.0.0.1:3000/api-docs.html) доступна при запущенном сервере. Спецификация хранится в [OpenAPI](docs/openapi.json).
- [Источники фотографий](docs/photos.md).
- `pnpm test` проверяет API на отдельной SQLite в памяти.

Сервис рассчитан на локальную демонстрацию с вымышленными данными и тестовыми учётными записями.
